### 7.370 Newest-row previews skip older Parquet row groups and retain direct single-group reads (2026-10-18, Codex; user: "revise the project anything to optimize", in English)

**Found.** `DatasetReader.tail` stopped after enough parts, but decoded every row group of each visited part to
show its last few rows. The Data tab and reward diagnostics use this path. Column projection and the one-open
contract from 7.286 were already in place; first-row previews and CSV streaming from 7.364 remain unchanged.

**Changed.** `_read_part` accepts an optional `tail_rows`. For a part with several row groups, it selects the
smallest suffix of groups containing the requested rows, then reads those groups in their original order. A
single-group part, or a request needing every group, uses the previous direct reader. Each visited file is opened
once and closed on success or failure. Each part contributes only the remaining requested rows to the final
