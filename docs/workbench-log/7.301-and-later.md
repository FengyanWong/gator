**What a rename is.** A saved model already has one (record 7.225: a Name box and Rename in its Details, a label file
beside the run, the run folder untouched). A task had none. A task's name is its key (`real:<name>`): its folder, its
Virtuoso cell, the task of every recorded run and saved model - and a run's archive is checksummed, so a recorded run
can never be rewritten to another key. So a task's rename is the same kind as a model's and a folder's: **the name it
is shown under**. The key, the files, the cell and every run and model stay; the windows show the new name, and new runs
of the task are filed under it.

**Built.**
- `src/gator_workbench/task_names.py` (new): `task_names.json` in the settings folder (`{version, names: {task key:
  shown name}}`), written under the folders' lock. `rename` refuses a task that is not registered, a name that is not a
  task name (`names.TASK_NAME`) and a name another task has or is shown under; the task's own name removes its entry.
  `shown` ignores a stored name that another task carries as its own (a task saved later under that name wins; nothing
  is rewritten). `names()` never fails the task list over an unreadable file; `forget` drops a deleted task's name.
- `tasks.list_tasks`: every task lists `name`; `task_registry.starter_project`: a renamed task's run label and project
  name are its shown name (three starter routes take it from there). `POST /api/tasks/rename` (`RenameTaskBody`): 404 /
  409 `name_taken` / 422. The two task delete routes forget the name.
- Page: `TaskList.tsx` - the Task column, the row's tooltip, the filter, the "Current task" line and the Project
  column's button show the shown name (`shownName`), a renamed row says "internal name ..." under it, Details opens
  with a Name box and Rename (the model's row and styles), and the facts gain "Internal name". `RunList.tsx`: the run's
  task link reads "ldo1_relaxed (real:graphgps_ldo1)". `TaskSave.tsx`: a shown name counts as taken for Save as.
  A server that lists no `name` (older than the page): the Name box is off and the button says why.
