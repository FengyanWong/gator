### 7.356 CircuitGPS version 3: averages where version 2 summed, opt-in (2026-10-16, Claude session "check codex work"; user: "fix the circuitgps according to chat")

**Why.** In Round 3 (records 7.353-7.354) fine-tuned GraphGPS matched or beat CircuitGPS on all four seen circuits. One
cause found in the recorded data: four sums in CircuitGPS grow with the size of the circuit - a spec's bindings into its
measurement program, the spec-to-node binding messages, the group-member messages and the readout's pools over nodes,
groups, specs and blocks. On one recorded state of each of the 65 Round 3 training tasks (15-123 nodes), the node pool
of a fresh version 2 readout had median RMS 15.0 beside 0.16 for the attended token read with it (Spearman with node
count 0.96), and the first critic's value reached 5.80 on the largest circuit. In the trained Round 3 model the inner
sums had grown further (median over states of the largest row RMS: spec-to-node messages 350, program bindings 126,
group members 75).

**What.** `architecture_version` 3 of CircuitGPS (`src/analog_optimizer/models/circuit_gps.py`): version 2 with
`segment_mean` in place of `segment_sum` at those four places. The program tree's own child sums (normalized after each
combine since version 2) and the critic's per-node sum of its groups' action tokens (a node is in few groups) stay. The
readout keeps its explicit log counts, so how many nodes, groups, specs and blocks there are is still an input. Weight
names and shapes are those of version 2. `ModelConfig` accepts 1-3 for CircuitGPS (default still 2) and 1 for every
other encoder. In the workbench, `run.network.architecture_version` (`schema.NetworkConfig`; unset = the encoder's
default; a version the encoder does not have is refused) reaches the model through `modes.model_config_from`; an offline
request names it in `model`. Unset or at the default it is hashed as absent, so every configuration keeps its hashes,
and unset it is not written, so a configuration saved now still loads in a frozen runtime or in a server not yet
restarted (checked against the f8ff5ce runtime: unset loads, 3 is refused). The page neither shows nor sets it: write it
in the configuration file. Choosing an encoder or its preset on the page returns it to the default, and a version 3 save
point chosen on the page is refused as another "network architecture" until the configuration states version 3.

**Measured at initialization (no training, no simulator).** The same 65 states, fresh networks from seed 0, version 2 ->
3: median |Q| 0.92 -> 0.11 (largest 5.80 -> 0.21); squared error against the recorded reward, median 1.40 -> 0.092
(largest 43.4 -> 0.48); node pool RMS, median 15.0 -> 0.62, Spearman with node count 0.96 -> 0.10; on the largest
circuit (the AgenticSizing system, 123 nodes) |Q| 5.80 -> 0.11. The trained Round 3 version 2 model gives bit-identical
values under the old and the new source (largest difference 0.0 on all 65 states).

**Tests.** `tests/test_circuit_gps.py` +3 (version 3 loads version 2 weights strictly and changes only the aggregation;
its readout pools are the means of the final tokens; eight identical bindings read as one); the version test now refuses
4. `tests/workbench/test_wb_circuit_gps.py` +1 (the setting reaches the model; hashes kept at the default; unset not
written; refused for other encoders; a MOCK version 3 run saves version 3 and only a version 3 network fine-tunes from
it). Linux-side copy (`~/gator-cgps-dev`), final code: package 781 passed, 20 skipped; the whole workbench suite 1324
passed, 1 skipped. Live tree: 27 passed (CircuitGPS and global encoders) after the model part, and no other pytest while
real runs were going; every changed file is byte-identical to the tested copy.

**Source digest.** analog_optimizer `ba551575...` (f8ff5ce) -> `6ebf5ba5...`. As after every source change, an exact
resume of a save point written before is refused; fine-tune and frozen loading only warn. Frozen runtimes are untouched:
the GATv2 runs of record 7.355 run in `~/gator-runtime-7301`, whose files their queue checks. 8765 keeps the code it
